## 🏛️ Code Standards & Architecture Guidelines

1. **Docstring Standard**: All new Python code files must start with a docstring at the top of the file explaining what the file does.
2. **Copyright Notice**: All new Python code files must start with a commented copyright statement for "Cymbal Direct" at the top of the file (e.g., `# Copyright (c) Cymbal Direct. All rights reserved.`).
3. **Agent Skills Directory**: All custom agent skills must be created in the root of the workspace under the `.agents/skills/` directory (e.g., `.agents/skills/<skill-name>/SKILL.md`).
